# agent-harness

Portable agent operating rules, templates, and small DSH plugins.

Not a dump of `~/.dsh`. Keep credentials, sessions, MCP tokens, and personal
memory notes out of this repo.

## Layout

- `AGENTS.md` — Accuracy Protocol (all coding agents)
- `templates/` — task spec + clean-context reviewer prompt
- `memory/INDEX.md` — empty index format only
- `vendor/` — local DSH plugins (MCP settings GUI, tool-arg coerce, replay dedup)
- `.agent-presets/` — optional DSH router presets

## This machine

Canonical live copies: `~/.agents/rules/harness-protocol.md` and
`~/.agents/templates/`. DSH runtime stays in `~/.dsh`.
